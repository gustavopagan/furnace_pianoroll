Furnace v0.6.8.3 with a per-channel piano roll window.

- Windows: `...-Windows-x86_64.zip`, unzip and run `furnace.exe`.
- macOS: `...-macOS-arm64.dmg` (Apple Silicon) or `...-macOS-x86_64.dmg` (Intel). First time: right-click > Open.
- Linux: `...-Linux-x86_64.tar.gz`, extract and run `./furnace`.

The executables are not code-signed.
